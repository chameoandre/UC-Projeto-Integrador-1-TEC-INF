## 📐 Padrão Oficial de Modelagem: draw.io

- **Ferramenta:** [draw.io (diagrams.net)](https://app.diagrams.net/)
- **Formato nos Repositórios:** Salvar como `docs/arquitetura.drawio.png` (ou `.svg`) para renderização direta no `README.md` do GitHub e facilidade de reedição.
- **Regra de Ouro:** O diagrama é um artefato vivo de consulta diária, orientando diretamente o desenvolvimento do código e a coleta de dados empíricos.
